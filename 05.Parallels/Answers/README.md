## How to Use These Files

1. **Compare answers across files** — When you find a question in BUILD.md that troubles you, read how EACH parallel answers it. The differences will reveal which model is strongest for that specific creative problem.

2. **Identify your primary parallel** — After reading all seven, mark which 2-3 answer documents felt most true to your vision. Those are the parallels that should form your screenplay's spine.

3. **Use the Synthesis file (P07) as your final reference** — P07 contains locked answers that represent the full integration of all six models. When in doubt, the P07 answer is the recommended starting point for any structural or thematic decision.

4. **Return after each draft milestone** — The BUILD.md Milestone Checkpoints in each file are designed to be revisited at every major draft stage, not just before writing begins.
